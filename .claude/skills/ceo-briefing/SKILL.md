# CEO Briefing Skill

## Purpose
Generate weekly Monday Morning CEO Briefing

## Trigger
Every Monday 8:00 AM or manual request

## Process
1. Read Dashboard.md for current metrics
2. Read Done/ folder for completed tasks
3. Read Business_Goals.md for targets
4. Generate briefing with Revenue, Bottlenecks, Suggestions
5. Save to CEO_Briefings/YYYY-MM-DD_Briefing.md

## Output Format
- Revenue this week vs target
- Completed tasks summary
- Bottlenecks identified
- Proactive suggestions
- Upcoming deadlines
